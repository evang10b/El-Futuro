# El-Futuro
A alarm clock that is powered by the XIAO ESP32 module, and a display– 2.25inch TFT Screen.

# Features
- 4 key buttons with thair own functions
- 1 buzzer
- 1 custom PCB powere by XIAO ESP32
- Custom Arduino Firmware
- 3d printed case
